ADSA Graph Algorithms & Viva Lab

Demonstrating Graph Theory, Breadth-First Search (BFS), Depth-First Search (DFS), and Complexity Analysis.

ALGORITHM 1

Breadth-First Search (BFS)

BFS explores vertices layer-by-layer using a First-In, First-Out (FIFO) Queue. It visits all 1-hop neighbors before proceeding to 2-hop neighbors, guaranteeing the shortest path (minimum edges) in unweighted graphs.

Metric Value
Time Complexity O(V + E)
Space Complexity O(V)
Data Structure Queue (FIFO) + Visited Set + Parent Map
Shortest Path Guarantee ✅ Yes (for unweighted graphs)
ALGORITHM 2

Depth-First Search (DFS)

DFS explores as deep as possible along each branch before backtracking using recursion or a LIFO Stack. Useful for cycle detection and connectivity, but does not guarantee the shortest path.

Metric Value
Time Complexity O(V + E)
Space Complexity O(V) (Recursion Call Stack)
Data Structure Recursion Stack + Visited Set
Shortest Path Guarantee ❌ No (Exploratory / Traversal)
